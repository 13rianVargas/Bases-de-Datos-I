# Bases de Datos I

Repositorio de ejemplos y recursos para el curso de Bases de Datos I.

## Contenido

### Ejemplos SQL

- **SELECT - Ejemplos.sql**: Ejemplos de consultas SELECT, incluyendo alias, WHERE, ORDER BY, LIKE, BETWEEN, IN, funciones de agregación y más.
- **GROUP BY - Ejemplos.sql**: Ejemplos de agrupación de datos con GROUP BY.
- **HAVING - Ejemplos.sql**: Ejemplos del uso de HAVING para filtrar grupos.
- **JOINS - Ejemplos.sql**: Ejemplos de INNER JOIN, LEFT JOIN y combinaciones de múltiples tablas.

### JSON & XML

Ejemplos de estructuras de datos en formato JSON y XML:
- `TablasDeEstudiantes.json`
- `TablasDeEstudiantes.xml`
